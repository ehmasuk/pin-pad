Description:

Share Note is a simple note keeping website where user can keep their note online. They can write down their note and can share the url to anyone to see and edit the note, they can make the note password safe

Requirements:

- User can write anything
- They can share link
- They can edit link
- Live collaborate
- Word counter and character counter
- Dark mode
- Font increase decrease
- Link highlighter and clickable and copy able
- Furnish text with ai
